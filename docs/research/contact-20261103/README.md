# 接触与轨迹切分进度（2026-11-03）

当前离线版本为 `native-release-v5`：12 条来源轨迹、4146 帧、197 段。
它是接触监督与切分复核的数据快照，不代表已完成新一轮策略训练。
完整统计见 [summary.json](summary.json)。

## 接触、支撑与点监督

- 接触真值来自 Newton/MJWarp 实际激活且分配了约束的原生 rows；有效主表面
  为地面和水平顶面。原始 rows 保留，几何距离和力阈值不能替代激活判断。
- 支撑载荷是施加在机器人上的正向世界 z 力之和，切向摩擦力不计入。
  首次落稳需要连续 5 帧超过 30 N 且位置、姿态、材料点运动收敛。
  建立支撑后使用 15 N、连续 2 帧的退出滞回；短暂同面静止缺口可在派生时序中桥接。
- 同一部位内部滚动、换点、row 切换和滑动不自动终止已建立的承重支撑。
  同部位转移必须有实际脱离证据；脚/膝主形式切换另外保留边界。
- 点 loss 有独立的逐帧有效掩码：相邻承重 rows 在部位坐标系中匹配，载荷稳定，
  材料点运动达标。接触持续不意味着每帧点目标都有效。
  原始稳定点监督共 1492 个有效部位帧。

## 整段切分及仍需解决的问题

保留区间由互不重叠的半开区间完整覆盖，无回溯扩窗或重复帧。四肢角色为
S 支撑 / T 转移 / N 不参与；下肢脚/膝是一侧的不同主接触形式。
起身、下蹲和保持接触的姿态调整可单独成段。首尾裁剪仅排除有证据的静止等待、
初始化下落、终末跌倒或未知接触区间，正常的首尾半步保留。
当前 12 条没有满足裁剪规则的首尾区间，实际裁剪为 0 帧。

长度中位数 23 帧、P90 29 帧、最长 49 帧；32 段不超过 10 帧，5 段超过 40 帧。
其中含源轨迹截断和临近落稳切点。初始承重只有几帧时，首次落稳确认可能尚未
建立，造成初始角色歧义。多个肢体的转移可以交叠，尤其在攀爬中；无需拆为
两套训练任务。当前按落稳与主形式切点分段，还没有完成针对交叠转移的边界修正，
不能把现有短段都解释成完整单步。

六条 `walk_*` 共 2394 帧中，有 31 个双脚同时无原生接触的采样，全部为单帧。
这是每个控制帧最后一次求解采样，不能推断完整 20 ms 的腾空时长，也不能以
桥接掩盖原始缺口。确认物理腾空需要所有物理子步证据。

## 重建与浏览器复核

使用已配置的 workflow 环境运行，输出写入被 git 忽略的 `tmp/`：

```bash
python packages/supermimic/tools/rebuild_contact_topology_library.py \
  --previous /path/to/native-source-captures --output tmp/contact-slices
python packages/supermimic/tools/export_contact_role_review.py \
  --dataset tmp/contact-slices \
  --task-manifest /path/to/original/task.json \
  --output tmp/contact-role-review
python -m http.server 18765 --bind 127.0.0.1 --directory tmp/contact-role-review
```

浏览 `/` 按角色查看，`/?review=length` 左右对照全部短段和长段，`/?case=50`
直达指定段。清单包含帧区间、角色、阶段及切点原因；支持逐帧、播放、速度和镜头控制。
可用 `--previous /path/to/previous-dataset` 保留前后版本的源帧重叠映射。
重建需要 `native-rows.pt`、对应采集报告与原始 recording；浏览器导出需要 `trimesh`。
原生采集、权重和约 56 MB 的导出轨迹是外部运行产物，本次提交包含可复现源码与统计，
不将这些本地文件宣称为已发布的数据 release。
